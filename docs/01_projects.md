> #### **spion** — это сахар для логирования в Python. Забудь про `print()` для отладки. Один декоратор — и ты уже знаешь, что происходит в коде.

**Фишки:**
*   **Минимум кода**: `@log()` или `@watch()` — и функция под колпаком.
*   **Глубинная разведка**: `@trace()` покажет рекурсию, `@state()` — изменения объектов.
*   **Без спама**: `@throttle()` задаст частоту, `@silent()` — только ошибки.
*   **100% покрытие**: 172 теста, всё работает на Python 3.7–3.14.

👉 **Установка одной командой:** `pip install spion`
